# Mode de paiement

## Définition

Moyen utilisé par le client pour régler sa facture : prélèvement, carte bancaire, virement ou autre.

## Où est stockée la donnée

Dans le **référentiel client**, avec les coordonnées de paiement associées (stockées de façon sécurisée).

## Comment la consulter

- Outil de gestion client : onglet « Paiement ».
- Espace client en ligne : rubrique « Mes moyens de paiement ».

## Qui peut la mettre à jour

- Le **client**, depuis son espace en ligne.
- Un **conseiller**, avec l'accord du client.

## Quand est-elle obligatoire

Toujours. Par défaut, le mode choisi à la souscription s'applique.

## Exemple

`Prélèvement automatique`
